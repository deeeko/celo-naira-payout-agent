How a payout runs

The same steps, in this order, on every run.

  1. Quote

    Gets a free price from Textile FX, then a firm quote for the exact amount.

  2. Convert

    Lets Textile's contract take the USD₮ if needed, then swaps it to cNGN in one transaction.

  3. Pay

    Sends exactly the cNGN the swap delivered to the approved recipient.

  4. Check

    Reads each transaction back from the chain and flags any that is missing the tag.

Limits the AI can't change

These are checks in the code (src/guards.mjs, src/pay.mjs). The optional AI only turns a request into a contact name and an amount. It never sees an address, and every rule below still applies.

  • Dry run unless told otherwise. Nothing moves without --execute. It then shows the amount and recipient and waits for you to type “yes”, unless you pass --yes to answer up front.
  • $25 per payout. Larger amounts are refused before any quote is requested. Only the owner can change the cap (MAX_USD).
  • Approved recipients only. Payees must be named in an allow-list. The agent's own address, wallets listed as the owner's, the token and registry contracts and the zero address are always refused.
  • No bad prices. It stops if the firm quote pays more than 3% (default) less cNGN than the preview, and won't send a swap whose quote has expired.
  • Pays what it received. The payout is the measured change in its cNGN balance, not an estimate.
  • Keys stay local. The private key sits in a file outside the repo. The code signs locally and never sends or prints it.
