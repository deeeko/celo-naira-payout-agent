How a payout runs

The same four steps, in order, every time.

  1. Quote

    Gets a free price from Textile FX, then a firm quote for the exact amount.

  2. Convert

    Swaps USD₮ to cNGN in one onchain transaction.

  3. Pay

    Sends exactly the cNGN the swap delivered to the named recipient.

  4. Check

    Reads each transaction back and confirms it carries the tag.

Limits it cannot talk its way past

These are rules in the code. The optional AI only reads a name and an amount from a request.

  • No payment without a yes. Every run is a dry run unless you add --execute and type "yes".
  • $25 per payout. Larger amounts are refused.
  • Known recipients only. Payees come from an allow-list. The agent's own wallet and the builder's wallets are blocked.
  • No bad prices. It stops if the firm quote is more than 3% worse than the preview, or has expired.
  • Pays what it received. The payout is the measured cNGN balance change, not an estimate.
  • Keys stay home. The private key never leaves the owner's machine and is never printed.
