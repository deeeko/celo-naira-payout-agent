How the check works

  1. Read. Fetches the transaction's calldata with eth_getTransactionByHash from Celo's Forno RPC.
  2. Find. Looks for the ERC-8021 marker 0x8021…8021 at the very end of the calldata.
  3. Decode. Reads the length and schema bytes before the marker, then decodes the attribution codes.

This agent tags every transaction it sends with celo_7360953d1b53. The page only reads data; it cannot send or move funds.
