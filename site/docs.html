How it works

What the agent does, the rules it enforces in code, and how to run it yourself.

Overview

Naira Payout is a command-line agent on Celo mainnet. It takes USD₮, converts it to cNGN (a naira stablecoin) through Textile FX, and sends the cNGN to a recipient you have approved in advance.

It is for people who hold dollars and need to pay someone in Nigeria in naira. The recipient gets cNGN in their Celo wallet and can redeem it for naira, for example through cngn.co.

Onchain: the agent's ERC-8004 identity (agent #10079), and every transaction it sends during a payout: the USD₮ approval (and an allowance reset, if one is needed), the swap and the cNGN transfer. Each one carries the attribution tag celo_7360953d1b53. Off chain: the Textile price quote, your contacts file, the agent's key file and a local receipts log.

This website is read-only. It shows live prices and onchain data but cannot move money. Payouts are run by the agent's owner from the command line.

How a payout runs

src/pay.mjs

  1. Quote

    Checks the amount against the cap and the recipient against the allow-list, then asks Textile FX for a free preview. A dry run stops here. With --execute it checks the wallet holds enough USD₮ and about 0.02 CELO for gas, asks you to confirm, then requests a firm quote.

  2. Convert

    If the current allowance is too low, approves exactly the amount the firm quote needs (resetting an old allowance to zero first), then broadcasts Textile's swap transaction. An expired quote is never sent.

  3. Pay

    Reads the agent's cNGN balance before and after the swap, and transfers exactly that difference to the recipient. No estimate is used.

  4. Check

    Reads every transaction it sent back from the chain (reset, approval, swap, payout), flags any that is missing the tag, and exits with an error if one is. It prints Celoscan links and appends a line to receipts.jsonl.

Safeguards

Enforced in src/guards.mjs
  • Dry run by default. Nothing is sent without --execute, and then it waits for you to type “yes” (or pass --yes).
  • $25 per payout. Larger amounts are refused before any quote is requested. The cap is set by MAX_USD.
  • Approved recipients only. Payees must be named in the contacts file. The agent's own address, the owner's own_wallets, the token and registry contracts and the zero address are blocked.
  • Price protection. The firm quote may be at most 3% worse than the preview (MAX_SLIPPAGE_BPS). Expired quotes are never sent.
  • Pays what it received. The payout is the measured change in the agent's cNGN balance, not an assumed amount.
  • Key stays local. The private key lives in a file outside the repo and is never printed.
  • AI cannot override limits. The optional AI only maps a request to a contact name and an amount. Code applies every rule above.

Quick start 
npm install
npm test
node src/agent.mjs keygen
cp contacts.example.json contacts.json
node src/agent.mjs quote --amount 10
node src/agent.mjs pay --to ada --amount 10

Add your recipient's address to contacts.json first. The last command is a dry run and sends nothing.

FAQ

Can this website send money?
No. The site is read-only. It has no wallet connection and holds no keys. It reads public data from Celo (Forno RPC and Blockscout) and a published rate file. Payouts are sent only by the agent, from the command line, after a firm quote and the owner's confirmation.
Where does the exchange rate come from?
From a free Textile FX preview for $10 of USD₮, which includes Textile's fee. A GitHub Action fetches it every 30 minutes and publishes it with the site. If the preview is unavailable, the site falls back to Textile's market bid for USD₮/NGN and labels it as before fees. A real payout always uses a fresh firm quote at the time it runs.
Is it custodial?
The agent wallet is meant to hold funds only for the payout in progress: the payer funds it, and one run converts the USD₮ and pays out the cNGN. The owner keeps the private key in a local file. This website never holds funds.
What is the attribution tag?
A short code, celo_7360953d1b53, appended to the data of every transaction the agent sends, following ERC-8021. It credits the transactions to this hackathon entry. It is public, not a secret. You can check any transaction for it on the Verify page or with verify <hash>.
What if the price moves?
Before converting, the agent compares the firm quote with the free preview. If the firm quote would pay more than 3% less cNGN, it stops and sends nothing. If the quote expires while the approval is confirming, the swap is not sent and you run it again for a fresh quote.
Can the AI change the limits?
No. The optional AI only turns a request like “send $10 to ada” into a contact name and an amount. It never sees an address. Code then looks up the name in your contacts and applies the cap, the allow-list and the price check, exactly as for pay.
